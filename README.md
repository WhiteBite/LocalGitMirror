# LocalGitMirror

**Зашифрованный зеркальный мост между рабочим и домашним компьютерами (плагин DocCache)**

LocalGitMirror — персональный инструмент, который соединяет закрытое корпоративное рабочее окружение со свободной домашней средой через один self-hosted зашифрованный сервер. Код, GitLab MR-переписка и корпоративные зависимости (gradle/npm) передаются как непрозрачные шифрованные блобы через HTTP-почтовый ящик. Никакого облака и сторонних сервисов. Полная картина — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), он главный.

## Возможности

*   **Шифрованный обмен**: все данные идут через `/api/documents/*`; на рабочем ноутбуке содержимое для EDR скрыто, дома сервер расшифровывает релейные потоки (deps, почтовый ящик, буфер, vault) и хранит их повторно зашифрованными под отдельным ключом `relay.key`. Подробности — в разделе Crypto в ARCHITECTURE.md.
*   **Ветки туда-обратно**: отправка и вытягивание git-бандлов из плагина DocCache или через CLI (`lgm send` / `lgm pull`).
*   **GitLab MR-цикл**: перенос MR-веток, заметок ревью и ответов между машинами, даже если дома нет доступа к GitLab.
*   **Корпоративные зависимости**: запрос недостающих gradle/npm артефактов с работы и применение их в локальные кэши дома.
*   **Четыре поверхности**: плагин IntelliJ (DocCache), веб-SPA (управление сервером), CLI `lgm.py`, MCP-сервер `lgm_mcp.py`. Они не взаимозаменяемы, см. таблицу в ARCHITECTURE.md.

## Быстрый старт

Сервер запускается только на домашнем ПК:

```bash
python run.py            # прод: HTTPS на порту 443, отдаёт собранный SPA
python run.py dev        # разработка: backend :8000 + Vite :5173
```

`start.bat` / `start.sh` — тонкие обёртки над `run.py`. Лаунчер сам создаёт `backend/venv`, ставит зависимости и генерирует самоподписанный сертификат `cert.pem` / `key.pem`.

На рабочем ПК сервер не запускается: там работают плагин DocCache (и опционально MCP), которые обращаются к домашнему серверу по HTTPS/LAN. Настройки подключения — в плагине (`baseUrl`, API-ключ).

## Конфигурация

Порты берутся из `.env`:

| Переменная | Значение по умолчанию | Что это |
|---|---|---|
| `WEB_PORT` | **443** | прод HTTPS (FastAPI + SPA + API) |
| `GIT_PORT` | **8444** | внутренний dulwich-демон, пользовательскому workflow не нужен |
| `REDIRECT_HTTP_PORT` | не задан | HTTP→HTTPS редирект выключен по умолчанию |

Другие ключи (`BASE_URL`, `API_KEY`, `SYNC_PASSWORD`, `STORAGE_PATH`, GitLab-трио) описаны в разделе Operational constants в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). `API_KEY` обязателен: без него все защищённые маршруты сервера отвечают 503 (fail-closed). `SYNC_PASSWORD` больше не нужен для MR-цикла и файлового почтового ящика — они ходят только по v3 relay-крипто к закреплённому ключу сервера.

## Архитектура

*   **Backend**: Python (FastAPI), роутеры `sync` / `deps` / `file_sync` и др. в `backend/app/routers/`
*   **Frontend**: Vue 3 SPA, собирается в `frontend/dist` и отдаётся бэкендом
*   **Плагин**: Kotlin, IntelliJ, отображаемое имя **DocCache**
*   **CLI / MCP**: `lgm.py` и `lgm_mcp.py`, оба генерируются из одного реестра операций `lgm_core/ops.py`
*   **Транспорт**: только шифрованный HTTP (`/api/documents/*`); сырой git smart-HTTP намеренно отключён, рабочий процесс не использует `git remote add` на зеркало
