# Документация системы настроек

Настройки сервера: бэкендное хранение (`storage/.lgm/settings.json`) и страница `/settings` в SPA. Это настройки веб-поверхности управления; плагин DocCache имеет собственные настройки (`Settings → Tools → DocCache`), они здесь не описаны.

## Быстрый старт

```bash
python run.py            # прод: HTTPS на WEB_PORT (443 по умолчанию), SPA раздаётся тем же сервером
```

Откройте `https://localhost/settings` (сервер на самоподписанном сертификате). Отдельный frontend-процесс для этого не нужен; при разработке - `python run.py dev` и `http://localhost:5173/settings`.

## Интерфейс (`frontend/src/views/Settings.vue`)

Две секции в боковой навигации:

### Общие
- **Репозиторий по умолчанию** (`general.default_repo`)
- **Путь к хранилищу** (`general.storage_path`) с кнопкой "Обзор..." - открывает нативный выбор папки на машине сервера (`POST /api/settings/browse`). При изменении пути интерфейс показывает предупреждение: после смены пути сервер нужно перезапустить, до перезапуска все роутеры продолжают работать со старым хранилищем.
- **Авто-синхронизация** (`general.auto_sync`)
- **Интервал обновления** (`general.refresh_interval`, 1-60 секунд)

### Git
- **Порт HTTPS сервера** (`git.port`) — значение хранится в настройках; фактический прослушиваемый порт сервер берёт из `WEB_PORT` в `.env` при запуске
- **Идентификация Git** (`git.user_name`, `git.user_email`) - прописывается в репозитории при синхронизации
- Блок текущего сетевого статуса (IP, порт сервера) - только чтение, из `GET /api/status`

Кнопки: **Сохранить** (POST текущей формы), **Сбросить** (заполняет форму значениями по умолчанию из `GET /api/settings/defaults`; фактическая запись происходит только при "Сохранить").

## API (`backend/app/routers/settings.py`)

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET   | `/api/settings` | Все текущие настройки |
| POST  | `/api/settings` | Частичное обновление секций (см. контракт ниже) |
| POST  | `/api/settings/browse` | Нативный выбор папки на хосте сервера |
| GET   | `/api/settings/defaults` | Значения по умолчанию |

Все маршруты под авторизацией (`API_KEY`, заголовок `X-Session-ID` или `Authorization: Bearer`).

### Контракт POST /api/settings

Тело - объект с необязательными секциями `general`, `git`, `ui`:

```json
{
  "git": {"port": 9000},
  "ui": {"theme": "light"}
}
```

- Секции частичные: присланная секция мержится поверх текущей по ключам, неприсланные секции не трогаются. Одновременные получастичные записи сериализуются локром менеджера, гонки read-modify-write нет.
- Неизвестное имя поля верхнего уровня - 422 (`extra="forbid"`): опечатка в названии секции не "сохраняется молча".
- Пустое тело (ни одной секции) - 422.
- Ответ: `{"success": true, "settings": {...}}` с полным новым состоянием.

Значений по умолчанию (`settings_manager.defaults`):

```python
{
    "general": {
        "default_repo": "default",
        "default_folder": "",
        "storage_path": "<текущий STORAGE_PATH>",
        "auto_sync": True,
        "refresh_interval": 5,
    },
    "git": {
        "port": 8081,
        "auto_start": True,
        "auto_commit": False,
        "user_name": "",
        "user_email": "",
    },
    "ui": {"theme": "dark", "font_size": 14, "show_system_log": True},
}
```

## Хранение

Файл настроек: `storage/.lgm/settings.json` (легаси-путь `storage/settings.json` читается, если нового файла нет). Создаётся автоматически при первом обращении; недопустимый JSON приводит к значениям по умолчанию.

## Примеры

```bash
# Получить настройки
curl -k -H "Authorization: Bearer $API_KEY" https://localhost/api/settings

# Изменить только порт git-секции, ничего не затерев
curl -k -X POST -H "Authorization: Bearer $API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"git": {"port": 9000}}' \
  https://localhost/api/settings
```

## Устранение неполадок

### Настройки не сохраняются
- Проверьте, что в теле есть хотя бы одна из `general` / `git` / `ui` - пустое тело даёт 422
- Неизвестное имя секции тоже 422 - проверьте орфографию
- Убедитесь, что папка хранилища доступна для записи

### Смена пути хранилища "не применилась"
Так и задумано: запись сохраняет новый путь, но все компоненты переоткроют его только после перезапуска сервера (`run.py`).
