## Architecture & deployment topology (READ FIRST)

Read [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) before touching the code. It is the single source of truth for what runs where.

- HOME PC runs everything: the mirror server (`run.py`, FastAPI + Vue SPA), the IntelliJ plugin, the MCP server, and the CLI (`lgm.py`).
- WORK PC runs the IntelliJ plugin (primary day-to-day surface) and optionally MCP; the server and the CLI never run there.
- Four surfaces (plugin, web SPA, CLI `lgm.py`, MCP `lgm_mcp.py`) are NOT interchangeable; the doc maps who-does-what.
- Machine role (`machineRole` auto|home|work in plugin settings) decides which automation each side runs.
- All data flows through one encrypted HTTP postbox on the home server; no cloud, no raw git protocol.
